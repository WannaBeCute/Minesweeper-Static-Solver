# 静态扫雷计算器 (Minesweeper Static Solver)

> 基于穷举算法的静态扫雷逻辑推理工具
## 📖 简介

**纸上扫雷逻辑求解器**是一个专门用于解决**静态扫雷谜题**的 Python 工具。与传统的交互式扫雷游戏不同，本工具接收一个静态的扫雷盘面（包含已知数字和未翻开方格），通过**穷举**和**DFS**，计算出雷的位置
